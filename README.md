# ⚡ CargoWise AI Workflow & Trigger Rule Generator

An enterprise-grade automation tool designed for global logistics and freight forwarding operations. Built using **Python, Streamlit, and Google Gemini API**, this application bridges the gap between complex operational requirements and technical system execution in **CargoWise**.

## 🚀 Features
* **Automated Rule Generation:** Instantly creates precise CargoWise Custom Triggers and Universal Event Manager (UEM) rules.
* **eAdaptor XML Error Management:** Generates validation logic to catch missing mandatory fields (Waybills, Partner IDs, Charge Codes) before inbound manifests fail.
* **System Optimization:** Streamlines backend configurations and registry rules to eliminate manual data triage and reduce shipment downtime.

## 🛠️ Tech Stack
* **Python**
* **Streamlit** (UI Framework)
* **Google GenAI API** (`gemini-3.8-flash`)
* **CargoWise eAdaptor XML, UEM & Custom Triggers**
